## **자유 주제: 고객 문의(CS) 자동 분류 및 부서별 맞춤 알림**

**1. 반복 업무 정의:**

고객이 Google Forms를 통해 문의를 남길 때마다, 담당자가 일일이 내용을 확인한 후 '기술 오류'는 개발팀에, '환불 요청'은 CS팀에 수동으로 전달하고 분류해야 하는 번거로운 작업

**2. 선정 도구:**

**Make** (선정 이유: Router 모듈을 활용한 조건별 분기 설계가 시각적으로 매우 직관적이며, 과제 제약 사항인 '무료 플랜' 범위 내에서 Google Forms와 Slack 연동을 완벽하게 구현할 수 있기 때문)

**3. 워크플로우 흐름:**


<img width="598" height="665" alt="image" src="https://github.com/user-attachments/assets/06a744cc-2006-4ddd-8a5b-f90390bd6629" />


- **1) Trigger:** Google Forms – Watch Responses (새로운 고객 문의 폼 제출 즉시 감지)
- **2) Router:** 문의 유형(카테고리) 데이터에 따라 세 갈래의 경로로 분기
- **3) Path A (기술 오류 경로):**
    - **Filter:** 고객의 '문의 내용'에 **'오류'** 키워드가 **포함** 된 경우
    - **Action 1:** Slack – Create a Message (개발팀 채널에 `🚨[오류 리포트]` 알림 및 문의 상세 내용 전송)
    - **Action 2:** Gmail – Send an Email (고객에게 *"기술 오류가 접수되어 개발팀에서 확인 중입니다"* 안내 메일 발송)
- **4) Path B (환불 요청 경로):**
    - **Filter:** 고객의 '문의 내용'에 **'환불'** 키워드가 **포함** 된 경우
    - **Action 3:** Slack – Create a Message (CS팀 채널에 `💸[환불 요청]` 알림 및 고객 정보 전송)
    - **Action 4:** Gmail – Send an Email (고객에게 *"환불 요청이 정상 접수되어 담당자가 처리 중입니다"* 안내 메일 발송)
- **5) Path C (일반 문의 경로 - 예외 처리):**
    - **Filter:** '오류', '환불' 키워드가 모두 포함되지 않은 경우 (Make의 Fallback route 활용)
    - **Action 5:** Slack – Create a Message (통합 CS 채널에 `💬[일반 문의 접수]` 알림 전송 및 고객 정보 전송)
    - **Action 6:** Gmail – Send an Email (고객에게 *"담당자가 내용을 확인한 후 빠르게 답변드리겠습니다."* 기본 안내 메일 발송)
