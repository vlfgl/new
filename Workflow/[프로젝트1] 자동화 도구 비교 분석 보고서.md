# **📊 [프로젝트 1] 자동화 도구 비교 분석 보고서**

### **1. 사용한 도구**

- **Make**
- **Zapier**

### **2. 구현 과정 요약**

- **목표:** 고객 만족도 조사 결과를 점수에 따라 분류하여 기록하고 알림을 보내는 자동화 시스템 구축
- **공통 워크플로우:**
    1. **Trigger(=시작점):** Google Forms에 새로운 설문 응답 제출
    2. **조건 분기:** 만족도 점수를 기준으로 긍정(4점 이상)과 부정(3점 이하) 경로로 나눔
    3. **Action(=처리):** 각 경로에 맞게 Google Sheets에 데이터를 기록하고, Gmail로 알림 메일 발송
- **구현 방식:**
    - **Make:** `Router` 모듈을 사용해 경로를 나누고, 각 경로를 이어주는 선(Link)에 `Filter`를 설정하여 조건을 부여함.

    - **Zapier:** `Paths` 기능을 사용하여 Path A(긍정)와 Path B(부정) 그룹을 만들고, 각 그룹 내부에 시트 기록과 이메일 발송 단계를 순차적으로 구성함.

### **3. 비교 항목 (5가지)**

| 비교 항목                | Make                                                     | Zapier                                      |
| :------------------- | :------------------------------------------------------- | :------------------------------------------ |
| **① UI/UX (화면 구성)**  | 2D 캔버스 기반의 **시각적 워크플로우**<br>전체 흐름을 한눈에 파악하기 좋음           | 위에서 아래로 이어지는 **단계형 방식**<br>순서대로 설정하기 쉬움     |
| **② 설정 난이도 및 조건 분기** | `Router`와 `Filter`를 사용해<br>복잡한 조건 분기를 세밀하게 설정 가능         | `Paths`를 사용해<br>조건별 작업을 직관적으로 설정 가능         |
| **③ 테스트 및 실행 확인**    | 실행 과정과 데이터 이동을 **시각적으로 확인**할 수 있음                        | 단계별 테스트와 **입·출력 데이터 확인**이 쉬움                |
| **④ 데이터 매핑 (연결)**    | 데이터가 **구조화된 형태**로 표시되어 필요한 값을 선택해 연결                     | 이전 단계의 데이터를 **드롭다운에서 선택**해 연결               |
| **⑤ 요금제 및 무료 플랜**    | 무료 플랜 **월 1,000 credits** 제공<br>`Router`, `Filter` 사용 가능 | 무료 플랜 **월 100 tasks** 제공<br>기본적인 2단계 자동화 지원 |



### **4. 어떤 상황에서 적합한지 (종합 의견)**

- **Make를 추천하는 상황:** 조건이 여러 갈래로 나뉘는 **복잡한 자동화**를 구축해야 하거나, 예산이 부족하여 **무료/저렴하게 많은 양의 작업**을 자동화해야 하는 스타트업 및 실무자에게 적합
- **Zapier를 추천하는 상황:** A를 하면 B를 한다는 식의 **단순한 1:1 자동화**가 필요하거나, 코딩이나 IT 지식이 전혀 없는 **초보자**가 빠르게 업무를 자동화하고 싶을 때, 혹은 국내외 **마이너한 앱들을 연동**해야 할 때 적합
