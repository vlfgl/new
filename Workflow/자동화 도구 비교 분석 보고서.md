# **📊 [프로젝트 1] 자동화 도구 비교 분석 보고서**

### **1. 사용한 도구**

- **Make**
- **Zapier**

### **2. 구현 과정 요약**

- **목표:** 고객 만족도 조사 결과를 점수에 따라 분류하여 기록하고 알림을 보내는 자동화 시스템 구축
- **공통 워크플로우:**
    1. **트리거:** Google Forms에 새로운 설문 응답 제출
    2. **조건 분기:** 만족도 점수를 기준으로 긍정(4점 이상)과 부정(3점 이하) 경로로 나눔
    3. **액션:** 각 경로에 맞게 Google Sheets에 데이터를 기록하고, Gmail로 알림 메일 발송
- **구현 방식:**
    - **Make:** `Router` 모듈을 사용해 경로를 나누고, 각 경로를 이어주는 선(Link)에 `Filter`를 설정하여 조건을 부여함.

    - **Zapier:** `Paths` 기능을 사용하여 Path A(긍정)와 Path B(부정) 그룹을 만들고, 각 그룹 내부에 시트 기록과 이메일 발송 단계를 순차적으로 구성함.

### **3. 비교 항목 (5가지)**

| 비교 항목 | Make | Zapier |
| :--- | :--- | :--- |
| **① UI/UX (화면 구성)** | 2D 캔버스 기반의 **시각적/마인드맵 방식**<br>(전체 흐름을 한눈에 파악하기 좋음) | 위에서 아래로 내려가는 **리스트/단계형 방식**<br>(글을 읽듯 순서대로 설정하여 직관적임) |
| **② 설정 난이도 및 조건 분기** | `Router`와 `Filter` 개념 이해가 필요하여<br>처음 진입 장벽이 다소 있음 | `Paths` 기능으로 A/B 그룹이 직관적으로 나뉘어<br>초보자가 이해하고 설정하기 쉬움 |
| **③ 테스트 및 실행 확인** | 데이터 이동이 애니메이션으로 보여<br>시각적으로 작동 원리 파악이 쉬움 | 단계별 테스트 진행.<br>단, 이전 조건을 무시하고 현재 데이터 형식만<br>테스트하는 경향이 있어 혼란을 줄 수 있음 |
| **④ 데이터 매핑 (연결)** | 데이터 구조가 트리 형태로 보이며,<br>알약 모양의 태그를 클릭해 삽입함 | 드롭다운에서 실제 들어온 데이터 값<br>(예: "5", "홍길동")을 직접 보며 선택 가능함 |
| **⑤ 요금제 및 무료 플랜** | 무료 월 1,000회 실행 가능.<br>복잡한 조건 분기(Router)도 무료 지원 (가성비 훌륭) | 무료 월 100회 실행 가능.<br>조건 분기(Paths) 등 3단계 이상은 유료 플랜 필요 |




### **5. 어떤 상황에서 적합한지 (종합 의견)**

- **Make를 추천하는 상황:**조건이 여러 갈래로 나뉘는 **복잡한 자동화**를 구축해야 하거나, 예산이 부족하여 **무료/저렴하게 많은 양의 작업**을 자동화해야 하는 스타트업 및 실무자에게 적합합니다.
- **Zapier를 추천하는 상황:**A를 하면 B를 한다는 식의 **단순한 1:1 자동화**가 필요하거나, 코딩이나 IT 지식이 전혀 없는 **초보자**가 빠르게 업무를 자동화하고 싶을 때, 혹은 국내외 **마이너한 앱들을 연동**해야 할 때 적합합니다.
